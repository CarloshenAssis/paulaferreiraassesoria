# Paula Ferreira Assessoria Contábil

Site institucional em HTML/CSS/JS estático para a Paula Ferreira Assessoria Contábil (União dos Palmares – AL).

## Estrutura

- `index.html` — página institucional (Hero, Sobre, Serviços, Diferenciais, Depoimentos, Instagram, Localização, CTA).
- `artigos.html` — página de artigos/blog com conteúdos contábeis.
- `css/style.css` — estilos do site.
- `js/main.js` — interações (menu mobile, abas de serviços, fallback de imagens).
- `images/` — fotos do site (ver `images/README.md` para os nomes de arquivo esperados).

## Como visualizar

Basta abrir `index.html` em um navegador, ou servir a pasta com qualquer servidor estático, por exemplo:

```
python3 -m http.server 8080
```

e acessar `http://localhost:8080`.
